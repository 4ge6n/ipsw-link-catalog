Download queue

Select files and add them to the queue. The queue is shared across every version and operating system on this site, so you can mix iOS and iPadOS files, then open one download at a time. After saving a file in Safari, return here and open the next one.

Download everything unattended

A browser is never told when a cross-origin download finishes, so it cannot start the next one by itself. Save the queue as a script and let curl work through it one file at a time, resuming anything interrupted.

Saving the script opens your system's save dialog, and the downloads land in whatever folder you pick there — a browser never reveals the path it chose, so the script works out its own location instead. Then, in Terminal, type bash and drag the saved script onto the window:

bash ipsw-queue.shIt prints each file's size and progress, counts what is finished, and skips files that are already complete, so it can be run again to retry. Both settings can still be overridden: bash ipsw-queue.sh /Volumes/IPSW 4
