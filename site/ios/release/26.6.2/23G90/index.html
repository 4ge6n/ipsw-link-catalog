Download queue

Select files and add them to the queue. The queue is shared across every version and operating system on this site, so you can mix iOS and iPadOS files, then open one download at a time. After saving a file in Safari, return here and open the next one.

Download everything unattended

A browser is never told when a cross-origin download finishes, so it cannot start the next one by itself. Save the queue and let curl work through it one file at a time, resuming anything interrupted.

cd ~/Downloads && xargs -n1 curl -fL -OC - < ipsw-queue.txt
