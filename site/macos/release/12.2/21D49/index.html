Released Jan 27, 2022 03:23 JSTJan 26, 2022 18:23 UTC

Download queue

Select files and add them to the queue. The queue is shared across every version and operating system on this site, so you can mix iOS and iPadOS files, then open one download at a time. After saving a file in Safari, return here and open the next one.

Download the whole queue unattended

A browser is never told when a download has finished, so it cannot start the next one on its own. This script can: it works through the queue for you, shows progress, and carries on where it left off.

  1. Choose how many download at once.
  2. Save the script where you want the files. The downloads land in the same folder as the script.
    Or type the folder to download into

    Set this and the script ignores where it was saved, downloading into this folder instead.

  3. Run it in Terminal. Type bash and a space, drag the saved script onto the Terminal window, then press Return.

    bash ipsw-queue.sh

It names each file with its size, counts off what is finished, and leaves completed files alone — so you can stop it at any time and run it again to collect the rest.
